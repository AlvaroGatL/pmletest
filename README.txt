PMLE PRACTICE LAB — 6 tests / 540 preguntas

1. Abrir PMLE_Practice_Lab_Interactivo.html en Chrome, Edge o Firefox.
2. Elegir Test 1 a Test 6 (o crear un simulacro mixto).
3. Seleccionar una o varias alternativas y pulsar «Confirmar respuesta».
   La clave, explicación del instructor y feedback sólo aparecen luego de confirmar.
4. Finalizar para ver el puntaje y el detalle por dominio.
5. Exportar el progreso a JSON para respaldarlo o importarlo en otro equipo.

CÓMO PUBLICARLO EN INTERNET
Subir el archivo HTML como index.html a cualquier hosting estático,
como GitHub Pages o Netlify. No necesita backend, librerías externas ni base de datos.
El progreso se guarda con localStorage en el navegador y NO se sincroniza entre dispositivos.

CRITERIOS DE PUNTAJE
- 1 punto por pregunta completamente correcta; 0 por incorrecta.
- Las preguntas sin responder dan 0 puntos en el puntaje final.
- Selección múltiple exige acertar todo el conjunto de alternativas.
- Test 4 pregunta 54 y Test 6 pregunta 9 contienen contradicciones entre
  clave y explicación; se muestran, pero se excluyen del puntaje.
- El porcentaje no representa la nota oficial de la certificación.
- Subtemas específicos se etiquetaron automáticamente, pueden solaparse.

CONTENIDO
Los enunciados y explicaciones se conservan del material aportado, salvo saneamiento
HTML de formato. No se ha realizado auditoría técnica independiente de todas las claves.
